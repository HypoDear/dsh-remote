# DSH Web 启动器

一个快捷方式，点一下弹菜单：**打开界面 / 重启 DSH / 停止 DSH**。

没有开机自启，没有崩溃自动重拉，没有常驻进程 —— 点完就退出，dsh 独立活着。

## 文件

| 文件 | 作用 |
|---|---|
| `open-dsh.ps1` | 全部逻辑都在这一个脚本里（菜单、启停、图标生成、快捷方式安装）。 |
| `README.md` | 本文件。 |

`%LOCALAPPDATA%\DSH\dsh.ico` 由脚本运行时生成，**不在仓库里**。

## 安装

```powershell
pwsh -File open-dsh.ps1 -Action install
```

会做两件事：

1. 从 DSH 自带的 `favicon.svg` 生成鲸鱼图标 → `%LOCALAPPDATA%\DSH\dsh.ico`
2. 在桌面创建 `DSH.lnk`

然后**手动固定到任务栏**：右键快捷方式 →「显示更多选项」→「固定到任务栏」。
Win11 也可以直接把它拖到任务栏上。

## 用法

日常只用点任务栏那个鲸鱼图标。也可以用参数直接调：

| 命令 | 作用 |
|---|---|
| `pwsh -File open-dsh.ps1` | 弹菜单（快捷方式走这条） |
| `... -Action open` | 已在跑就切过去/开浏览器；没跑就先启动 |
| `... -Action restart` | 杀掉 → 等端口释放 → 启动 → 开浏览器 |
| `... -Action stop` | 杀掉 → 等端口释放 |
| `... -Action status` | 只打印状态（诊断用） |
| `... -Action install` | 生成图标 + 创建快捷方式 |

`-NoBrowser` 抑制打开浏览器，`-WhatIf` 只打印不执行。

## 几个刻意的设计

**为什么是「点一下弹菜单」而不是右键菜单**
任务栏图标的右键永远属于 Windows 自己（「固定到任务栏 / 关闭窗口」），第三方
无法接管。能做右键菜单的只有系统托盘图标，但那需要一个常驻进程一直活着 ——
与「最小方式」直接冲突。托盘方案另需一个常驻进程盯着，性质和从前的守卫进程一样。

**重启为什么能真的重启**
新实例用 `Start-Process` 启动，与脚本脱钩：脚本退出后 dsh 继续活。
所以不需要任何托管机制，也就不需要计划任务。

**启动时带 `--no-open`**
`dsh web` 默认自己会开浏览器（日志里的 `dsh web: opening the default browser`）。
本脚本在端口就绪后自己开一次，两边都开就会冒两个标签 —— 这是「重复打开」的
主要来源。

**开浏览器前先找已开的标签**
用 UI Automation 遍历浏览器标签（窗口标题只显示活动标签，抓不到后台标签），
标题含 `DeepSeek Harness` 就切过去，不再新开。找不到才开新标签。

已知取舍：若将来同时跑多个 DSH 实例，会被认成同一个。当前只跑一个实例。

UIA 不可用时静默降级为直接打开 —— 这个功能是锦上添花，不该挡住「打开界面」。

## 性能

状态探测曾经用 `Get-NetTCPConnection`，实测 **1886ms**，菜单明显卡顿。
现在改用 `TcpClient` 直连探测端口（**35ms**，快 50 倍），进程识别先用
`Get-Process -Name node` 快速筛再查命令行。`status` 从 4 秒降到约 0.9 秒。

## 图标为什么是生成的

`.lnk` 的 `IconLocation` 只接受文件路径，不支持内嵌图像。所以要么在仓库里放
一个 `.ico` 二进制，要么运行时造一个。选了后者，仓库里就只有脚本。

生成的 `.ico` 里 **48px 及以下必须是 BMP(DIB) 格式**，不能是 PNG：
Explorer 为任务栏/桌面取小图标时只走 BMP 解码路径，PNG 条目在那些尺寸下会
渲染成**空白图标**。只有 256×256 用 PNG。

## 编码

`open-dsh.ps1` 含中文，存成 **UTF-8 with BOM**。
无 BOM 时 Windows PowerShell 5.1 会按 ANSI 解码，中文注释会撕碎后续代码；
pwsh 7 虽能正确识别，但保持带 BOM 可让两个版本都能跑。

## 日志

`~/.dsh/logs/dsh-web.log`（dsh 自身的 stdout），`dsh-web.log.err`（stderr）。
超过 2MB 自动轮转为 `.old`。
